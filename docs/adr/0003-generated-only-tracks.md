# Generated-only Tracks; Daily and Weekly are the core loop

Every Track comes from the generator as a pure function: (generator version, difficulty class, seed) to segment list. There is no editor and no hand-authored Track; content supply is the Daily Challenge, the Weekly Challenge, and Generate and Share. Track Codes carry the generator version, so generator changes never rewrite existing Tracks or their Leaderboards; old versions stay frozen.

**Considered options**: hand-authored tracks (rejected: content supply was not the launch bottleneck); block-editor UGC (deferred until the core loop proves fun); curated numbered set (rejected in favor of date-derived Daily/Weekly plus seed sharing).
